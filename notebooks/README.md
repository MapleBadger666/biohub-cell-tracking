# Exploratory notebook archive

The 14 numbered notebooks preserve the original markdown and code cell sources, covering data exploration, official metric checks, cross-validation, baseline inference, sparse-label training, edge recovery, and Stage12 research.

All execution counts, outputs, and attachments are removed from these public copies. Original execution evidence is retained locally under `reports/notebook_execution_archive_20260928/`, which is excluded from GitHub. Source hashes and the archive mapping are recorded in [the source archive manifest](../docs/evidence/source_archive_manifest_20260928.json).

These are historical exploration records. They contain local paths, repeated experiments, and repair cells; they are not a sequence to execute blindly. Reusable implementations belong in `src/biohub_cell_tracking/` and `scripts/`. Their historical numerical results do not establish a new validated improvement.

The reviewed Kaggle notebook and offline environment builder are in [submission/](submission/README.md).
